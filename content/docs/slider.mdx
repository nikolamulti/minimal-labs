## Usage

### Basic slider

Simple slider with default configuration.

<SvelteComponent height={80} url="/slider" />

```svelte
<Slider value={[25]} />
```

### Range slider

Support for selecting a range of values using multiple thumbs.

<SvelteComponent height={80} url="/slider/range" />

```svelte
<Slider value={[25, 75]} />
```

### Disabled slider

Slider can be disabled to prevent user interaction.

<SvelteComponent height={80} url="/slider/disabled" />

```svelte
<Slider disabled value={[50]} />
```
