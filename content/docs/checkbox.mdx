## Component API

The Checkbox component accepts several props for customization:

<TypeTable
  type={{
    id: {
      description: "Unique identifier for the checkbox",
      type: "string",
      default: "required",
    },
    variant: {
      description: "Visual style variant of the checkbox",
      type: "string",
      default: "default",
    },
    disabled: {
      description: "Whether the checkbox is disabled",
      type: "boolean",
      default: "false",
    },
    isError: {
      description: "Whether to display the checkbox in error state",
      type: "boolean",
      default: "false",
    },
  }}
/>

>
