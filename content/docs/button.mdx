## Variants

The Button component supports five different variants:

<SvelteComponent height={80} url="/button/variants" />

```svelte
<script>
  import { Button } from '@/components/button';
</script>

<Button variant="default">Default</Button>
<Button variant="primary">Primary</Button>
<Button variant="danger">Danger</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
```

- `default`: Standard button style
- `primary`: Emphasized button style for primary actions
- `danger`: Button style for destructive or dangerous actions
- `outline`: Button with an outline style
- `ghost`: Button with a transparent background

## Icon support

Built-in support for `startIcon` and `endIcon` props, allowing you to enhance the button's visual communication and functionality with custom icon components.

<SvelteComponent height={80} url="/button/icon-support" />

```svelte
<script>
  import { Button } from '@/components/button';
</script>

<Button startIcon={ArrowLeft}>Previous</Button>
<Button endIcon={ArrowRight}>Next</Button>
```

## Using as a link

Built-in support for `href` prop, allowing you to use the button as a link.

<SvelteComponent height={80} url="/button/link" />

```svelte

  import { Button } from '@/components/button';
</script>

<Button href="/">Home</Button>
<Button href="/">About</Button>
```
