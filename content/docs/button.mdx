## Usage

Import the Button component and use it in your Svelte application:

```svelte
<script>
  import { Button } from '@/components/button';
</script>

<Button variant="primary">Click me</Button>
```

## Variants

The Button component supports five different variants:

<SvelteComponent height={80} url="/button/variants" />

```svelte
<Button variant="primary">Submit</Button>
<Button variant="danger">Delete</Button>
<Button variant="outline">Cancel</Button>
<Button variant="ghost">Close</Button>
```

- `default`: Standard button style
- `primary`: Emphasized button style for primary actions
- `danger`: Button style for destructive or dangerous actions
- `outline`: Button with an outline style
- `ghost`: Button with a transparent background

## Accessibility

The Button component is built with accessibility in mind:

1. It uses the native `<button>` element for proper semantics and keyboard navigation
2. It supports focus states for keyboard users
3. The loading state is communicated visually and can be detected by assistive technologies
4. Disabled states are properly handled, preventing interaction and indicating the button is unavailable

## Best Practices

1. Use the appropriate variant for the button's purpose (e.g., `primary` for main actions, `danger` for destructive actions)
2. Provide clear and concise text for the button label
3. Use the `loading` state for asynchronous actions to provide visual feedback
4. Utilize `startIcon` and `endIcon` props to enhance the button's meaning when appropriate
5. Ensure sufficient color contrast between the button and its background for all variants

For more details on implementation or advanced usage, please refer to the source code or contact the development team.
