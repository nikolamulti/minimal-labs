---
title: Installation
description: Learn how to install and use the Webflow Svelte CLI to add components to your project
---

import { Tabs, Tab } from "fumadocs-ui/components/tabs";
import { Step, Steps } from "fumadocs-ui/components/steps";

<Steps>
  <Step>
    Install the CLI package using your preferred package manager:

    <Tabs items={["npm", "pnpm", "yarn"]}>
      <Tab value="npm">

      ```bash
      npm install webflow-svelte-cli
      ```

      </Tab>
      <Tab value="pnpm">

      ```bash
      pnpm add webflow-svelte-cli
      ```

      </Tab>
      <Tab value="yarn">

      ```bash
      yarn add webflow-svelte-cli
      ```

      </Tab>
    </Tabs>

  </Step>

  <Step>
    After installation, run `wfs init` to initialize your components:

    <Tabs items={["npm", "pnpm", "yarn"]}>
      <Tab value="npm">

      ```bash
      npm wfs init
      ```

      </Tab>
      <Tab value="pnpm">

      ```bash
      pnpm wfs init
      ```

      </Tab>
      <Tab value="yarn">

      ```bash
      yarn wfs init
      ```

      </Tab>
    </Tabs>

  </Step>
  <Step>
    The CLI will prompt you to enter your license key. You can find your license key in your <a href="https://app.lemonsqueezy.com/dashboard" target="_blank">Lemon Squeezy</a> account. This key is required to access and install the components:

    ```bash
    ┌ WFS Initialization
    │
    ◇ Please enter your license key:
    │ ▮
    │
    ◇ Successfully validated license
    ```

  </Step>

  <Step>

    After validating your license, you'll be guided through choosing where to install the CSS file, selecting a location for the components, and installing all available components.

    ```bash
    ◇ Installation path for wfs.css:
    │ ./src
    │
    ◇ wfs.css created successfully
    │
    ◇ Installation path for components:
    │ ./src/lib/components
    │
    ◇ Successfully installed 25 components
    │
    └ You're all set!
    ```

  </Step>

  <Step>
  
    Import the `wfs.css` file in your main application file.

    ```js
    import './wfs.css';
    ```

  </Step>

  <Step>

    You can now start using the components in your project. Check out the components section to learn how to use them.

  </Step>
</Steps>

## Commands

| Command      | Description                                       |
| ------------ | ------------------------------------------------- |
| `init`       | Initialize the project and install all components |
| `activate`   | Activate a license                                |
| `deactivate` | Deactivate the license                            |
| `help`       | Display this help message                         |
