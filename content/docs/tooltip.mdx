```svelte
<script>

  import { Tooltip, TooltipTrigger, TooltipContent, TooltipArrow } from '@/components/tooltip';

<Tooltip>
	<TooltipTrigger>
		<Button>Hover me</Button>

</Tooltip>
```

## Component API

The Tooltip component consists of multiple parts, each accepting specific props for customization.

<TypeTable
  type={{
    side: {
      description: "Placement of the tooltip relative to the trigger element",
      type: "'top' | 'right' | 'bottom' | 'left'",
      default: "'top'",
    },
    align: {
      description: "Alignment along the trigger element's axis",
      type: "'start' | 'center' | 'end'",
      default: "'center'",
    },
    sideOffset: {
      description: "Distance in pixels between tooltip and trigger element",
      type: "number",
      default: "'5'",
    },
    sameWidth: {
      description: "Whether tooltip should match the width of its trigger",
      type: "boolean",
      default: "'false'",
    },
    avoidCollisions: {
      description:
        "Automatically adjust position when tooltip would overflow viewport",
      type: "boolean",
      default: "'true'",
    },
  }}
/>

>

### TooltipArrow

Optional visual arrow element that points to the trigger.

## Positioning

The tooltip can be positioned on any side of the trigger element:

<SvelteComponent height={160} url="/tooltip/positioning" />

```svelte
<Tooltip>
  <TooltipTrigger>
    <Button>Top</Button>
  </TooltipTrigger>
  <TooltipContent side="top">
    <TooltipArrow />
    Top tooltip
  </TooltipContent>
</Tooltip>

<Tooltip>
  <TooltipTrigger>
    <Button>Right</Button>
  </TooltipTrigger>
  <TooltipContent side="right">
    <TooltipArrow />
    Right tooltip
  </TooltipContent>
</Tooltip>
```

## Alignment

Control the alignment of the tooltip relative to its trigger:

<SvelteComponent height={160} url="/tooltip/alignment" />

```svelte
<Tooltip>
  <TooltipTrigger>
    <Button>Aligned</Button>
  </TooltipTrigger>
  <TooltipContent align="start">
    <TooltipArrow />
    Start aligned tooltip
  </TooltipContent>
</Tooltip>
```

## Width Control

Use `sameWidth` to match tooltip width with trigger:

<SvelteComponent height={160} url="/tooltip/width-control" />
```svelte
<Tooltip>
  <TooltipTrigger>
    <Button>Same Width</Button>
  </TooltipTrigger>
  <TooltipContent sameWidth={true}>
    <TooltipArrow />
    This tooltip will match trigger width
  </TooltipContent>
</Tooltip>
```

## Collision Avoidance

The tooltip automatically adjusts its position to stay within the viewport:

<SvelteComponent height={160} url="/tooltip/collision-avoidance" />
```svelte
<Tooltip>
  <TooltipTrigger>
    <Button>Smart Positioning</Button>
  </TooltipTrigger>
  <TooltipContent avoidCollisions={true} sideOffset={10}>
    <TooltipArrow />
    This tooltip will reposition to stay visible
  </TooltipContent>
</Tooltip>
```
