## Usage

```svelte
<script lang="ts">
  import { Switch, SwitchField } from '$lib/components/switch';
  import { Label } from '$lib/components/fieldset';

  let emailNotifications = false;
</script>
```

```svelte
<SwitchField>
  <Switch id="notifications" bind:checked={emailNotifications} />
  <Label for="notifications">Email Notifications</Label>
</SwitchField>
```

## Properties

The `Switch` component extends the Bits UI `<Switch>` component. Find the full list of available properties in the official Bits UI <a href="https://www.bits-ui.com/docs/components/switch" target="_blank">documentation</a>.

### Reversed

Place the `Switch` last in the `SwitchField` component to make the switch appear on the right side of the label.
