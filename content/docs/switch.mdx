## Event Handling

Component supports various interaction events.

```svelte
<script>
  function handleChange(checked) {
    console.log('Switch state:', checked);
  }

  function handleClick(event) {
    console.log('Switch clicked:', event);
  }
</script>

<Switch
  onCheckedChange={handleChange}
  onClick={handleClick}
>
  Auto-save
</Switch>
```
