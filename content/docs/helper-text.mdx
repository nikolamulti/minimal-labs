## Usage with form elements

Helper text is commonly used in conjunction with form inputs to provide context or validation messages.

<SvelteComponent height={100} url="/helper/form" />

```svelte
<script>
  import { Helper } from '@/components/helper';
  import { Input } from '@/components/input';
</script>

<Input placeholder="Enter your email" />
<Helper>We'll never share your email with anyone else</Helper>

<Input placeholder="Password" type="password" />
<Helper state="error">Password must be at least 8 characters long</Helper>
```
