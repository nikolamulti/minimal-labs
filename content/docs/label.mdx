## Component API

The Label component accepts various props for customization:

<TypeTable
  type={{
    sublabel: {
      description: "Additional text displayed below the main label",
      type: "string",
      default: "null",
    },
    showQuestionIcon: {
      description: "Displays a question mark icon next to the label",
      type: "boolean",
      default: "false",
    },
    isRequired: {
      description: "Adds a required indicator to the label",
      type: "boolean",
      default: "false",
    },
  }}
/>
