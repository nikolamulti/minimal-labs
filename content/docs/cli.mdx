## Installation

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">npm install webflow-svelte-cli -g</Tab>
  <Tab value="pnpm">pnpm add -g webflow-svelte-cli</Tab>
  <Tab value="yarn">yarn global add webflow-svelte-cli</Tab>
  <Tab value="bun">bun add -g webflow-svelte-cli</Tab>
</Tabs>

## Usage

After installation, you can use the CLI by running the `wfs` command followed by a specific command:

```bash
wfs <command>
```

## Available Commands

### init

Use the `init` command to initialize your project with Webflow Svelte components.

```bash
wfs init
```

This command performs the following steps:

<Steps>
  <Step>Checks for an existing license key in the config</Step>
  <Step>Prompts the user to enter a license key if not found</Step>
  <Step>Activates the license</Step>
  <Step>Saves the configuration</Step>
  <Step>Initializes the project (creates/updates globals.css)</Step>
  <Step>Installs the bits-ui package</Step>
  <Step>Logs a success message</Step>
</Steps>

### activate

Activates a license for the Webflow Svelte components.

```bash
wfs activate
```

This command:

<Steps>
  <Step>Prompts the user to enter a license key</Step>
  <Step>Activates the license using the provided key</Step>
  <Step>Saves the license key and instance ID in the configuration</Step>
  <Step>Optionally allows the user to add components immediately</Step>
</Steps>

### deactivate

Deactivates the current license for the Webflow Svelte components.

```bash
pnpm wfs deactivate
```

This command:

<Steps>
  <Step>
    Retrieves the current license key and instance ID from the configuration
  </Step>
  <Step>Deactivates the license</Step>
  <Step>Removes the license information from the configuration</Step>
</Steps>

### add

Adds Webflow Svelte components to your project.

```bash
pnpm wfs add [component]
```

If a specific component is provided, it will be added immediately. Otherwise, the command will:

<Steps>
  <Step>Fetch available components</Step>
  <Step>Allow the user to select components to install</Step>
  <Step>Install the selected components</Step>
</Steps>

Example:

```bash
pnpm wfs add button
```

### help

Displays help information about available commands.

```bash
pnpm wfs help
```

This command shows a list of all available commands and their descriptions.

## Command Options

```bash
init [options]
Options:
  -y, --yes         skip confirmation prompt (default: false)
  -f, --force       force overwrite of existing configuration (default: false)
  -c, --cwd <cwd>   the working directory (default: current directory)
  -h, --help        display help for command

activate [options]
Options:
  -k, --key <key>   specify the license key
  -y, --yes         skip confirmation prompt (default: false)
  -h, --help        display help for command

deactivate [options]
Options:
  -y, --yes         skip confirmation prompt (default: false)
  -h, --help        display help for command

add [options] [components...]
Arguments:
  components        the components to add
Options:
  -y, --yes         skip confirmation prompt (default: false)
  -o, --overwrite   overwrite existing files (default: false)
  -c, --cwd <cwd>   the working directory (default: current directory)
  -p, --path <path> the path to add the component to
  -h, --help        display help for command
```

## Monorepo

In a monorepo, you can specify the path to your workspace with the `-c` or `--cwd` option.

```bash
pnpm wfs init -c ./apps/web
```

or

```bash
pnpm wfs add button -c ./apps/web
```

For more details on the implementation of each command, refer to the source code or contact the Webflow Svelte team.
