## Features

### Single item

Default behavior allows only one item to be opened at a time.

<SvelteComponent height={100} url="/accordion" />

```svelte
<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger>Accordion</AccordionTrigger>
    <AccordionContent>Lorem ipsum dolor sit amet adipisicing elit. Quisquam, quos.</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Multiple items

Enable opening multiple items simultaneously using the multiple prop.

<SvelteComponent height={160} url="/accordion/multiple" />

```svelte
<Accordion multiple>
  <AccordionItem value="item-1">
    <AccordionTrigger>Accordion</AccordionTrigger>
    <AccordionContent>Lorem ipsum dolor sit amet adipisicing elit. Quisquam, quos.</AccordionContent>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Accordion</AccordionTrigger>
    <AccordionContent>Lorem ipsum dolor sit amet adipisicing elit. Quisquam, quos.</AccordionContent>
  </AccordionItem>
</Accordion>
```
