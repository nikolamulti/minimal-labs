## Component API

The Avatar component accepts various props for customization:


## Variants

### Image

Displays a profile picture.

<SvelteComponent height={80} url="/avatar/image" />

```svelte
<script>
  import { Avatar } from '@/components/avatar';
</script>

<Avatar size="sm" image="https://picsum.photos/300" />
<Avatar size="md" image="https://picsum.photos/300" />
<Avatar size="lg" image="https://picsum.photos/300" />
```

### Icon

Shows an icon when no image is available.

<SvelteComponent height={80} url="/avatar/icon" />

```svelte
<script>
  import { Avatar } from '@/components/avatar';
</script>

<Avatar size="sm" icon="https://picsum.photos/300" />
<Avatar size="md" icon="https://picsum.photos/300" />
<Avatar size="lg" icon="https://picsum.photos/300" />
```

### Fallback

Displays initials or a placeholder when no image or icon is provided.

<SvelteComponent height={80} url="/avatar/fallback" />

```svelte
<script>
  import { Avatar } from '@/components/avatar';
</script>

<Avatar size="sm" fallback="AA" color="neutral" />
<Avatar size="md" fallback="AA" color="neutral" />
<Avatar size="lg" fallback="AA" color="neutral" />
```
