## Component API

The Progress component accepts several props for customization:

<TypeTable
  type={{
    value: {
      description: "The current progress value (0-100)",
      type: "number",
      default: "required",
    },
    variant: {
      description: "The visual style of the progress bar",
      type: "primary | neutral | success | warning | critical",
      default: "primary",
    },
  }}
/>

>

## Variants

The Progress component supports five different variants:

<SvelteComponent height={160} url="/progress/variants" />

```svelte
<Progress value={20} variant="primary" />
<Progress value={40} variant="neutral" />
<Progress value={60} variant="success" />
<Progress value={80} variant="warning" />
<Progress value={20} variant="critical" />
```
