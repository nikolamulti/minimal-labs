## Usage

```svelte
<script lang="ts">
  import { Progress } from '$lib/components/progress';

  let value = 70;
</script>
```

```svelte
<Progress bind:value variant="primary" />
```

## Properties

The `Progress` component extends the Bits UI `<Progress>` component. Find the full list of available properties in the official Bits UI <a href="https://www.bits-ui.com/docs/components/progress" target="_blank">documentation</a>.
