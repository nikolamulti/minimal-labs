## Usage

### Default spinner

Basic spinner with default size of 24px.

<SvelteComponent height={80} url="/spinner" />

```svelte
<Spinner />
```

### Custom size

Spinner size can be customized using the size prop.

<SvelteComponent height={80} url="/spinner/sizes" />

```svelte
<Spinner size={16} />
<Spinner size={24} />
<Spinner size={32} />
```
