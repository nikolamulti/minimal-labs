<SvelteComponent url="/note" />

```svelte
<script>
 import { Note, NoteIcon, NoteContent, NoteTitle, NoteDescription, NoteLink } from '$lib/components/note';
 import { Account } from '$lib/components/icons';
</script>

<Note variant="primary" style="solid" fullWidth={true} closable={true}>
 <NoteIcon icon={Account} />
 <NoteContent>
   <NoteTitle>Title text here</NoteTitle>
   <NoteDescription>Description text here</NoteDescription>
   <NoteLink variant="primary" underline={true}>Action 1</NoteLink>
 </NoteContent>
</Note>
```

## Variants

The Note component supports four different variants:

<SvelteComponent height={400} url="/note/variants" />

```svelte
<Note variant="primary">Primary Note</Note>
<Note variant="success">Success Note</Note>
<Note variant="warning">Warning Note</Note>
<Note variant="critical">Critical Note</Note>
```

## Styles

The Note component supports three different styles:

<SvelteComponent height={360} url="/note/style" />

```svelte
<Note style="solid">Solid Note</Note>
<Note style="faded">Faded Note</Note>
<Note style="outline">Outline Note</Note>
```

## Width

Control the width of the Note component:

<SvelteComponent url="/note/full-width" />

```svelte
<Note fullWidth={true}>Full Width Note</Note>
<Note fullWidth={false}>Default Width Note</Note>
```

## Orientation

Choose between horizontal and vertical layouts:

<SvelteComponent url="/note/orientation" />

```svelte
<Note orientation="horizontal">Horizontal Note</Note>
<Note orientation="vertical">Vertical Note</Note>
```

## Closable

Add a close button to the Note:

<SvelteComponent url="/note/closable" />

```svelte
<Note variant="primary" style="solid" fullWidth={true} orientation="horizontal" closable={true}>
			<NoteIcon icon={Account} />
			<NoteContent>
				<NoteTitle>Title</NoteTitle>
				<NoteDescription>Description</NoteDescription>
				<NoteLink variant="primary" underline={true}>Action</NoteLink>
			</NoteContent>
		</Note>
		<Note
			variant="primary"
			style="solid"
			fullWidth={true}
			orientation="horizontal"
			closable={false}
		>
			<NoteIcon icon={Account} />
			<NoteContent>
				<NoteTitle>Title</NoteTitle>
				<NoteDescription>Description</NoteDescription>
				<NoteLink variant="primary" underline={true}>Action</NoteLink>
			</NoteContent>
		</Note>
```

## Subcomponents

The Note component is composed of several subcomponents for flexible content structuring:
NoteIcon: Add an icon to the Note
NoteContent: Wrapper for the Note's content
NoteTitle: Title of the Note
NoteDescription: Description or body text of the Note
NoteLink: Action link within the Note

```svelte
<Note>
  <NoteIcon icon={Account} />
  <NoteContent>
    <NoteTitle>Title</NoteTitle>
    <NoteDescription>Description</NoteDescription>
    <NoteLink>Action</NoteLink>
  </NoteContent>
</Note>
```

## Accessibility

The Note component is designed with accessibility in mind. It uses semantic HTML and ARIA attributes to ensure proper screen reader support and keyboard navigation.
