## Usage

```svelte
<script lang="ts">
  import { Link } from '$lib/components/link';
</script>
```

```svelte
<Link href="https://webflow.com">Link text</Link>
```

## Properties

The `Link` component extends the Bits UI `<Button>` component. Find the full list of available properties in the official Bits UI <a href="https://www.bits-ui.com/docs/components/button" target="_blank">documentation</a>.

## Examples

### Icon support

Use the `leadingIcon` and `trailingIcon` properties to add an icon to the link.

<DocsTabs items={["Preview", "Code"]}>
  <DocsTab value="Preview" className="mt-6">
    <Svelte url="/link/icon-support" height={360} />
  </DocsTab>
  <DocsTab value="Code">

```svelte
<script lang="ts">
  import { Link } from '$lib/components/link';
  import { ChevronSmallLeft, ChevronSmallRight } from '$lib/components/icons';
</script>

<Link leadingIcon={ChevronSmallLeft}>Previous</Link>
<Link trailingIcon={ChevronSmallRight}>Next</Link>
```

  </DocsTab>
</DocsTabs>

### Variants

Use the `variant` property to change the appearance of the link.

<DocsTabs items={["Preview", "Code"]}>
  <DocsTab value="Preview" className="mt-6">
    <Svelte url="/link/variants" height={360} />
  </DocsTab>
  <DocsTab value="Code">

```svelte
<script lang="ts">
  import { Link } from '$lib/components/link';
</script>

<Link variant="primary" href="https://webflow.com">Primary link</Link>
<Link variant="white" href="https://webflow.com">White link</Link>
<Link variant="critical" href="https://webflow.com">Critical link</Link>
<Link variant="warning" href="https://webflow.com">Warning link</Link>
<Link variant="success" href="https://webflow.com">Success link</Link>
```

  </DocsTab>
</DocsTabs>

### Button

When a Link component is used without an `href` property, it will automatically behave like a button.

  </DocsTab>
