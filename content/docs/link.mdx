## Component API

The Link component accepts various props for customization:

<TypeTable
  type={{
    href: {
      description: "The URL the link points to",
      type: "string",
      default: "required",
    },
    variant: {
      description: "The visual style of the link",
      type: "default | primary | success | warning | critical",
      default: "default",
    },
    underline: {
      description: "Whether to show an underline",
      type: "boolean",
      default: "false",
    },
    disabled: {
      description: "Whether the link is disabled",
      type: "boolean",
      default: "false",
    },
  }}
/>

## Variants

The Link component supports five different variants:

<SvelteComponent height={80} url="/link/variants" />

```svelte
<script>
 import { Link } from '@/components/link';
</script>

<Link variant="default" href="#">
  Default
</Link>
<Link variant="primary" href="#">
  Primary
</Link>
<Link variant="success" href="#">
  Success
</Link>
<Link variant="warning" href="#">
  Warning
</Link>
<Link variant="critical" href="#">
  Critical
</Link>
```
